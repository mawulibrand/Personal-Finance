# Personal Finance & Wealth Management System

A Ghana-first platform for understanding cash flow, tracking wealth, planning financial goals, and reviewing possible financial strategies. GHS is the initial default currency.

## Project requirements

- [Full project brief](docs/project-brief.txt)
- [Delivery phases and acceptance criteria](docs/delivery-phases.txt)

The supplied documents are preserved as the project baseline. The first Phase 1 slice is implemented locally: a web app, API, email worker, and identity/Personal Space database schema. See [local development](docs/local-development.md) for setup and current verification limits.

## Core principles

- All MVP financial data is entered manually.
- Deterministic financial calculations use decimal arithmetic and PostgreSQL NUMERIC values.
- Financial records belong to a Financial Space, with authorization enforced before access.
- Personal information remains private when a user joins a household; sharing requires explicit permission.
- AI explains validated facts and proposes alternatives. Users approve or modify plans.
- Core records and calculations remain available during AI-provider outages.
- The MVP excludes custody, money transfers, investment execution, bank/Mobile Money synchronization, statement imports, and automatic market-price feeds.

## Architecture baseline

TypeScript modular monolith with a Next.js PWA, NestJS API and worker, PostgreSQL, Prisma, Redis/BullMQ, pnpm workspaces, Turborepo, and Docker. Shared packages separate financial calculations, analytics, authorization, validation, and AI orchestration.

Direct dependency versions are pinned in package manifests. The workspace lockfile must be generated by a successful installation before reproducible CI/deployment is available. The implementation targets Node 24, Next.js 16, NestJS 12, Prisma 7, and BullMQ 6.

## Delivery order

1. Foundation: monorepo, infrastructure, authentication, email verification, Personal Spaces, authorization, auditing, CI, health checks, logging, and staging.
2. Personal finance: categories, income, flexible paydays, salary confirmation, expenses, recurring records, budgets, dashboard, and net cash flow.
3. Wealth foundation: savings, liabilities, repayments, goals, snapshots, net worth, and payday routines.
4. Investments: accounts, transactions, valuations, fixed deposits, and maturities.
5. Portfolio intelligence: independently verified deterministic analytics.
6. Scenario planning: projections, assumptions, comparisons, and plan conversion.
7. AI financial intelligence: profile snapshots, rules, strategies, feedback, and approved plans.
8. Household finance: roles, invitations, ownership, dependants, and selective sharing.
9. Engagement: achievements, routines, and notification preferences.
10. Currency and discovery: historical FX and verified external provider directory.
11. Production hardening: MFA, recovery, security checks, backups, monitoring, exports, and deletion.

Each feature is delivered as a vertical slice covering persistence, backend, authorization, validation, frontend, and appropriate automated verification.

## First milestone

Phase 1 acceptance: a user can register, verify their email, sign in, and access their private Personal Financial Space.

The first implementation slice establishes the workspace and local services and implements this registration-to-private-dashboard flow. Full verification and staging deployment still require running database services and deployment configuration. No deployment is configured yet.
